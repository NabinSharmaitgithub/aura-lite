Open source · On-device · Offline-first

An AI agent that lives in your phone — and follows your rules.

AURA Lite reads your screen, plans multi-step tasks, and drives apps through an Accessibility Service. Its 50 device tools are available to the on-device agent and to any MCP client you pair — same contract, same audit log, same safety gates. No AURA cloud. No required account. No telemetry by default.

How it works

Three steps, then the phone works for you.

1. Grant what it needs

Accessibility, microphone, notifications. Explicit, per-permission onboarding; revoke anything, anytime, with the big Pause pill or by switching the service off.

2. Point AURA at your LLM

14 built-in presets (OpenAI, Anthropic, Groq, Google, Ollama, and more) plus a custom OpenAI-compatible endpoint. Your key stays in EncryptedSharedPreferences on the device.

3. Ask for something

"Reply to my last WhatsApp message", "book the next train", "what do I have this week?" AURA perceives, acts, and re-reads the screen to verify — no blind typing.

The tool surface

50 tools, one contract.

The same ToolCatalog backs the on-device agent and external MCP clients. You get full coverage of everyday tasks:

  • Screen read_screen · perceive_screen · get_screenshot · wait_for · verify_action
  • Touch tap · swipe · scroll · type_text · set_value · press_enter · press_key
  • Apps launch_app · lookup_app · open_deeplink · resolve_deeplink · list_app_deeplinks · system_intent
  • Files find_files · open_file · upload_file · download_file · clipboard · resolve_contact
  • Browser browser_open/read/find/act/extract/tabs/wait/screenshot/upload/handoff/close
  • Media volume · media_control · get_media_sessions · read_notifications · notification_action · dismiss_notification
  • Safety ask_user · run_steps (bounded batches) · end_session
Privacy

Your phone is the server. We built it that way.

  • Offline The agent, gates, and memory run entirely on-device. Web search (web_search) is the only outbound call, and only with your Tavily key.
  • Opt-in cloud Firebase sync and Backblaze B2 file backup exist, sit behind explicit Settings toggles, and default to off.
  • No tracker No analytics SDKs, no crash reporting unless you turn it on, no remote kill-switch unless you turn it on.
  • Hard blocks Banking, payment, wallets and authenticators are always closed to the agent — regardless of instructions.
  • Audit Every step is logged in an on-device trace you can read, export, or delete.

For builders

Speak MCP to a real phone.

Pair from any MCP client on the same network — Claude Code, Cursor, VS Code — and AURA Lite's 50 tools are available over LAN HTTPS/JSON-RPC with PIN pairing and per-device revocation.

claude mcp add aura -- aura-mcp

Same contract, same safety gates, same audit log — whether the action comes from the phone's agent or a paired desktop client.

The desktop bridge (aura-mcp-connect) is in active development; the LAN HTTPS transport works today.
